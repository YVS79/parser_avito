# 📶 USB 4G модем ZTE MF823D: работа парсера через модем и смена IP

Документ описывает доработку, которая позволяет парсеру:

1. автоматически находить USB 4G модем **ZTE MF823D** (и совместимые ZTE);
2. направлять трафик парсера **только через модем**, даже если на компьютере
   одновременно подключены Wi-Fi или Ethernet;
3. при блокировке Avito (HTTP 403/429/439) **менять IP модема** командой в
   веб-интерфейс модема;
4. делать это максимально быстро: сначала переподключение PDN (2–5 секунд),
   затем, если IP не изменился, — смена стандарта сети (LTE → 3G → LTE) с
   перерегистрацией у оператора.

> Модем MF823D по умолчанию работает в режиме «сетевой карты» (CDC
> Ethernet/RNDIS): компьютер получает адрес `192.168.0.x`, а веб-интерфейс
> модема доступен по адресу `http://192.168.0.1`. COM-порт и AT-команды для
> управления **не нужны** — используется CGI-API модема.

---

## Как это работает

```
AvitoParser / parser_cls
        │  HTTPS через локальный прокси 127.0.0.1:<port>
        ▼
Локальный egress-прокси (parser/modem/egress.py)
        │  IP_UNICAST_IF = индекс интерфейса модема
        ▼
Сетевой адаптер модема (192.168.0.x)
        │
        ▼
ZTE MF823D ── LTE/3G/2G ── оператор
        ▲
        │  CGI-команды: DISCONNECT_NETWORK / CONNECT_NETWORK /
        │  SET_BEARER_PREFERENCE
Управление модемом (parser/modem/zte.py)
```

* **Привязка к модему.** Обычного `bind()` к IP модема недостаточно: Windows
  выбирает исходящий интерфейс по таблице маршрутов, и трафик может уйти в
  Wi-Fi. Поэтому для каждого исходящего сокета выставляется
  `IP_UNICAST_IF` (Windows) — это принудительно направляет соединение в
  интерфейс модема. Права администратора не требуются, остальной трафик
  компьютера не затрагивается.
* **Управление модемом.** CGI-запросы идут напрямую на `192.168.0.1`
  (локальная сеть, не через интернет).
* **Смена IP.** `DISCONNECT_NETWORK` + `CONNECT_NETWORK` пересоздают PDN-
  соединение — это самый быстрый способ получить новый адрес. Если оператор
  выдал тот же IP, выполняется `SET_BEARER_PREFERENCE` (смена стандарта сети),
  модем перерегистрируется у оператора, после чего возвращается
  предпочтительный режим.

## Поддерживаемые модемы

| Модем | Режим | Управление |
|---|---|---|
| **ZTE MF823D** | RNDIS/HiLink, `192.168.0.1` | CGI `goform` |
| ZTE MF823, MF79U, MF920 и другие ZTE с веб-интерфейсом `goform` | RNDIS/HiLink | CGI `goform` |
| Huawei, Quectel и др. | — | пока не поддерживаются (нужен свой драйвер команд) |

Если у вашего ZTE другой адрес веб-интерфейса (например, `192.168.32.1`),
укажите его в `modem_gateway` — автоопределение проверяет и типовые адреса.

## Быстрая настройка

### 1. Подготовьте модем

1. Вставьте SIM-карту, отключите PIN-код (или введите его в веб-интерфейсе).
2. Подключите модем к USB и дождитесь сетевого адаптера с адресом
   `192.168.0.x`.
3. Откройте в браузере `http://192.168.0.1` — веб-интерфейс должен
   открываться.
4. Включите автоподключение к сети (чтобы модем сам поднимал интернет):
   `http://192.168.0.1/goform/goform_set_cmd_process?goformId=SET_CONNECTION_MODE&ConnectionMode=auto_dial`
   (если команда не срабатывает — включите автодозвон галочкой в веб-интерфейсе).

> Если веб-интерфейс просит пароль и вы его меняли — укажите пароль в
> настройке `modem_password`.

### 2. Включите режим модема в парсере

В GUI откройте раздел **«🌐 Прокси и обход блокировок»** → карточка
**«USB 4G модем (ZTE MF823D)»**:

* поставьте галочку **«Работать через USB 4G модем»**;
* адрес модема оставьте пустым (автоопределение);
* при необходимости укажите пароль веб-интерфейса;
* выберите способ смены IP (по умолчанию — «Быстро, затем смена стандарта»);
* нажмите **«Проверить модем»** — в логе появятся адрес, оператор, сеть,
  сигнал и текущий IP.

Либо пропишите в `config.toml`:

```toml
use_usb_modem = true
modem_gateway = ""                # пусто = автоопределение (192.168.0.1)
modem_password = ""               # пароль веб-интерфейса, если задан
modem_rotation_strategy = "fast_then_mode"
modem_preferred_mode = "NETWORK_auto"
modem_fast_timeout = 8
modem_mode_timeout = 45
modem_fast_attempts = 2
```

### 3. Настройте скорость реакции на блокировку

Для максимально быстрой смены IP:

```toml
block_threshold = 1      # менять IP после первой же блокировки
retry_delay = 1          # пауза перед повтором после смены IP, сек
modem_rotation_strategy = "fast_then_mode"
modem_fast_timeout = 6
modem_fast_attempts = 2
```

В GUI это поля **«Попыток перед разблокировкой»** и **«Пауза между неудачными
повторами»** в разделе «⚙️ Поведение парсера».

Итоговая задержка при блокировке обычно составляет **3–6 секунд**:
переподключение PDN + повторный запрос.

## Стратегии смены IP

| `modem_rotation_strategy` | Что делает | Типичное время |
|---|---|---|
| `fast` | Только `DISCONNECT_NETWORK` → `CONNECT_NETWORK` | **2–5 с** |
| `mode` | `SET_BEARER_PREFERENCE` (LTE → 3G → LTE) + переподключение | 10–40 с |
| `fast_then_mode` (по умолчанию) | Сначала `fast`; если IP тот же — `mode` | 3–6 с или 15–45 с |

Почему по умолчанию не всегда `mode`: смена стандарта сети заставляет модем
заново регистрироваться у оператора и занимает десятки секунд. В большинстве
случаев для нового IP достаточно переподключения PDN. Если оператор часто
выдаёт тот же адрес — включите `mode` или оставьте `fast_then_mode`.

### Максимально быстрый вариант

```toml
block_threshold = 1
retry_delay = 1
modem_rotation_strategy = "fast"
modem_fast_timeout = 6
modem_fast_attempts = 1
```

Если после этого Avito всё ещё блокирует (оператор вернул тот же IP),
переключитесь на `fast_then_mode` или `mode`.

## Параметры `config.toml`

| Параметр | По умолчанию | Описание |
|---|---|---|
| `use_usb_modem` | `false` | Работать через USB-модем |
| `modem_gateway` | `""` | Адрес веб-интерфейса; пусто = автоопределение |
| `modem_local_ip` | `""` | Локальный IP модема (если автоопределение ошибается) |
| `modem_interface` | `""` | Имя/индекс интерфейса модема (например, `12` или `Ethernet 2`) |
| `modem_password` | `""` | Пароль веб-интерфейса модема |
| `modem_rotation_strategy` | `fast_then_mode` | `fast`, `mode`, `fast_then_mode` |
| `modem_preferred_mode` | `NETWORK_auto` | Режим, в который возвращается модем: `NETWORK_auto`, `Only_LTE`, `Only_WCDMA`, `Only_GSM`, `WCDMA_AND_LTE` и др. |
| `modem_fast_timeout` | `8` | Ожидание нового IP после быстрого переподключения, с |
| `modem_mode_timeout` | `45` | Ожидание регистрации после смены стандарта, с |
| `modem_fast_attempts` | `2` | Попыток быстрого переподключения до смены стандарта |
| `modem_reboot_on_fail` | `false` | Перезагрузить модем, если IP не изменился (медленно) |
| `modem_bind_interface` | `true` | Привязывать сокеты к интерфейсу модема |

Если одновременно заданы `use_usb_modem` и обычный прокси, приоритет у
модема; в лог пишется предупреждение.

## Какие команды отправляются

Все команды — GET/POST на `http://192.168.0.1/goform/...` с обязательным
заголовком `Referer`. Без него модем отвечает `{"result":"failure"}`.

| Действие | Запрос |
|---|---|
| Текущий WAN IP | `goform_get_cmd_process?cmd=wan_ipaddr&multi_data=1` |
| Статус | `goform_get_cmd_process?cmd=network_provider,network_type,wan_ipaddr,...` |
| Отключить PDN | `goform_set_cmd_process?goformId=DISCONNECT_NETWORK` |
| Подключить PDN | `goform_set_cmd_process?goformId=CONNECT_NETWORK` |
| Сменить стандарт | `goform_set_cmd_process?goformId=SET_BEARER_PREFERENCE&BearerPreference=Only_LTE` |
| Перезагрузить | `goform_set_cmd_process?goformId=REBOOT_DEVICE` |

Допустимые значения `BearerPreference`: `NETWORK_auto`, `WCDMA_preferred`,
`GSM_preferred`, `Only_GSM`, `Only_WCDMA`, `Only_LTE`, `WCDMA_AND_GSM`,
`WCDMA_AND_LTE`, `GSM_AND_LTE`.

## Проверка без GUI

```bash
python scripts/modem_cli.py --status
python scripts/modem_cli.py --rotate
python scripts/modem_cli.py --rotate --strategy mode --preferred Only_LTE
python scripts/modem_cli.py --rotate --repeat 3 --delay 2
```

Утилита печатает адрес модема, оператора, сеть, сигнал, WAN IP, а для
`--rotate` — старый IP, новый IP и время смены.

## Диагностика

### «USB 4G модем не найден»

1. Проверьте, что в браузере открывается `http://192.168.0.1`.
2. Проверьте сетевой адаптер: `ipconfig` — должен быть адрес `192.168.0.x` и
   шлюз `192.168.0.1`.
3. Если адрес другой (например, `192.168.32.1`), укажите
   `modem_gateway = "192.168.32.1"`.
4. Если веб-интерфейс требует пароль — укажите `modem_password`.
5. Отключите VPN/виртуальные адаптеры, которые могут перехватывать
   `192.168.0.1`.

### «Веб-интерфейс модема требует авторизацию»

Укажите пароль администратора модема в `modem_password` (в GUI — поле
«Пароль веб-интерфейса модема»). Пароль хранится в `config.toml` в открытом
виде, как и пароль прокси.

### IP не меняется

* Оператор может выдавать адрес из CGNAT (`100.64.x.x`) и сохранять его.
  Попробуйте `modem_rotation_strategy = "mode"` и подождите 30–60 секунд.
* Включите `modem_reboot_on_fail = true` (крайняя мера, ~1–2 минуты).
* Проверьте баланс и ограничения тарифа — при исчерпанном трафике некоторые
  операторы не меняют IP.
* Убедитесь, что модем не в режиме «только 2G» с нестабильным покрытием:
  `modem_preferred_mode = "NETWORK_auto"`.

### Трафик всё равно идёт через Wi-Fi

* Убедитесь, что в логе есть строка «привязка трафика: ... ifindex=...».
* Укажите вручную `modem_interface` (номер ifindex из лога) или
  `modem_local_ip` (например, `192.168.0.100`).
* Проверьте, что в `config.toml` не задан обычный прокси: при
  `use_usb_modem = true` он игнорируется.

### Смена IP занимает слишком долго

* Поставьте `modem_rotation_strategy = "fast"`.
* Уменьшите `modem_fast_timeout` до 5–6 секунд.
* Поставьте `block_threshold = 1` и `retry_delay = 1`.

## Ограничения

* Поддерживается только IPv4 (модем раздаёт IPv4).
* Сравнение IP идёт по WAN-адресу модема (`wan_ipaddr`). Если оператор
  использует CGNAT, внешний адрес может отличаться от WAN; смена WAN обычно
  меняет и внешний адрес, но не гарантируется.
* Прошивки ZTE отличаются набором CGI-полей. Если модем не отдаёт часть
  статуса, парсер всё равно работает — просто в логе будет меньше данных.
* При смене стандарта сети интернет пропадает на 10–40 секунд — это
  нормально.
